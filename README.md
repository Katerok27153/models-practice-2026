## О репозитории

В этом репозитории собраны программные реализации моделей, разработанных в рамках учебной практики по теме **«Мультимодельный подход в решении задач кибербезопасности»**.  
Цель работы — практическое освоение методов математического и имитационного моделирования для анализа киберугроз и распространения вредоносного ПО в сетях.

Все модели реализованы на языке **Julia** с использованием пакетов `DifferentialEquations.jl`, `Plots.jl`, `Distributions.jl` и др.

## Содержание работ

| № | Модель / Метод | Описание |
|---|----------------|-----------|
| 1 | **Kathará** | Установка и настройка эмуляции сетевых топологий (Linux-контейнеры) |
| 2 | **SIR (ODE)** | Классическая эпидемиологическая модель (восприимчивые → заражённые → выздоровевшие) |
| 3 | **Лотки–Вольтерра** | Модель «хищник–жертва» |
| 4 | **Агентная SIR** | Многоузловая симуляция с миграцией, смертностью, повторным заражением |
| 5 | **Пуассоновские атаки** | Вероятностное моделирование потока атак на веб-сервер |
| 6 | **Графы атак** | DFS-поиск путей, Дейкстра с log-весами, PageRank, in-degree |
| 7 | **Сети Петри** | Задача обедающих философов (классика + арбитр), deadlock-анализ |

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Katerok27153/models-practice-2026.git
cd models-practice-2026
```

2. Убедитесь, что установлена **Julia 1.9+** и добавлены необходимые пакеты:

```julia
using Pkg
Pkg.add(["DifferentialEquations", "Plots", "Distributions", "DataFrames", "Graphs", "GraphRecipes", "FFTW"])
```

3. Каждая модель находится в отдельной директории. Внутри неё расположена папка ```project/```, которая содержит:

	- ```scripts/``` - исполняемые скрипты модели
	- ```Project.toml``` и ```Manifest.toml``` - файлы окружения Julia

Перейдите в директорию модели и затем в ```project/``. Выполните команду, указав путь к папке project как окружение, и путь к скрипту внутри scripts:

```
cd модель
julia --project=. scripts/скрипт-модели.jl
```

4. После этого можно посмотреть результирующие графики в папке ```project/plots``` и другие результаты в соответствующих директориях
